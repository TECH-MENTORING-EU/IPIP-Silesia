# IPIP Silesia

Boilerplate aplikacji **.NET 10 + Razor Pages + React** przygotowany jako szkic portalu łączącego edukację, networking i wejście na rynek pracy.

## Co jest w środku

- landing page z motywem przewodnim i roadmapą po maturze,
- repozytorium projektów edukacyjnych,
- sekcja networkingowa,
- sekcja z przykładowymi fizycznymi ofertami pracy,
- React osadzony w aplikacji Razor Pages jako interaktywne widgety.

## Uruchomienie

```bash
cd /home/runner/work/IPIP-Silesia/IPIP-Silesia/IPIP.Silesia.Web
dotnet run
```

Podczas `dotnet build` i `dotnet run` projekt automatycznie buduje frontend React.
